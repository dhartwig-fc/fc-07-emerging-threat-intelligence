# Emerging Threat Intelligence Library

## Overview

The Emerging Threat Intelligence Library provides a structured framework for monitoring, assessing and documenting evolving financial crime risks.

The repository focuses on emerging typologies, regulatory developments, industry intelligence and future detection opportunities across Anti-Money Laundering (AML), Trade-Based Money Laundering (TBML), sanctions evasion, fraud, digital assets and AI-enabled financial crime.

The objective is to support horizon scanning, scenario engineering, analytics development and future control design by translating emerging threats into actionable intelligence and potential detection capabilities.
